# ئەسلى ئامبارنى ئىز قوغلاش

LOSFER Minis ئوچۇق كودلۇق [OpenMinis/OpenMinis](https://github.com/OpenMinis/OpenMinis) تۈرى ئاساسىدا قۇرۇلغان. بۇ ھۆججەت ئەسلى ئامباردىكى يېڭىلىقلارنى قانداق ئىز قوغلايدىغانلىقىمىزنى، قايسى يېڭى ئىقتىدارلارنىڭ بىزنىڭ تۈرگە كىرگۈزۈلگەنلىكىنى ۋە ھەر قېتىملىق يېڭىلاشتا قانداق مەجبۇرىي باسقۇچلارنىڭ ئىجرا قىلىنىدىغانلىقىنى چۈشەندۈرىدۇ.

> **دىققەت:** ئەسلى ئامبار `1.16-beta.1` دىن `1.16-beta.7` غىچە بولغان سىناق نەشرلىرىنى پەقەت APK شەكلىدە ئېلان قىلدى؛ `0-beta-build39` … `0-beta-build45` خەتكۈچلىرىنىڭ ھەممىسى `1a71df0` (يەنى `1.15` مۇقىم نەشرىدىن كېيىنكى بىردىنبىر كود يوللاش) غا ئىشارە قىلىدۇ. شۇڭا بۇ يېڭى ئىقتىدارلارنىڭ **ئەسلى كودى ئېلان قىلىنمىغان**، `git merge` ياكى `cherry-pick` بىلەن بىۋاسىتە ئەكىرىش مۇمكىن ئەمەس. ئىز قوغلاش قورالى ئەسلى ئامبارنىڭ كودى ئېلان قىلىنغان ھامان ئۇنى بايقاپ، ئاپتوماتىك يېڭى نەشر چىقىرىدۇ. شۇڭا ھەر بىر سىناق نەشرىنىڭ يېڭى ئىقتىدارلىرى بۇ ھۆججەتتىكى ئىز قوغلاش جەدۋىلىگە تولۇق كىرگۈزۈلىدۇ ۋە بىزنىڭ رەسمىي نەشرىمىزمۇ بىر قەدەم ئۆستۈرۈلۈپ قايتا قۇرۇلىدۇ.

## ئاپتوماتلاشقان جەريان

[`.github/workflows/upstream-follow.yml`](../.github/workflows/upstream-follow.yml) ھەر كۈنى UTC 02:00 دە، شۇنداقلا قولدا قوزغىتىلغاندا ئىجرا بولىدۇ. [`scripts/track_upstream.py`](../scripts/track_upstream.py) ئەسلى ئامبارنىڭ Release، خەتكۈچ ۋە كود يوللاشلىرىنى ئاۋۋال بىۋاسىتە GitHub API دىن ئوقۇيدۇ (ئەينەك `https://gh-proxy.com/` بەزىدە كونا تىزىملىكنى ساقلاپ قالىدۇ، شۇڭا ئۇ پەقەت زاپاس يول)، ئاندىن ھالەتنى بۇ ھۆججەتكە ۋە [`upstream-state.json`](../upstream-state.json) غا يازىدۇ. ئىز قوغلاش قورالى نەشر خاتىرىسىنىڭ «يېڭى ئىقتىدار»، «تۈزىتىش» ۋە «كۆرۈنۈش ياخشىلاش» بۆلەكلىرىنىڭ **ھەممىسىنى** ئايرىم-ئايرىم خاتىرىلەيدۇ.

## بولاق نامى قائىدىسى

ئەپ ئىچىدىكى يېڭىلاش تەكشۈرۈشى بولاق نامىدىن نەشر، قۇرۇش نومۇرى ۋە ABI نى ئوقۇيدۇ. ئىككى فورمات قوللىنىدۇ:

| فورمات | مىسال |
| --- | --- |
| LOSFER (ھازىرقى) | `LOSFER-Minis-1.21-build43-arm64-v8a.apk` |
| ئەسلى ئامبار (ماسلىشىش ئۈچۈن ساقلاندى) | `MinisApp-1.16-build32-arm64-v8a.apk` |

`UpdatePolicy.chooseApk()` ئۈسكۈنىنىڭ ABI غا ماس كېلىدىغان APK نى تاللايدۇ؛ `UpdatePolicy.formalPackages()` بىر نەشردىكى **ھەر بىر** APK/AAB نى ئايرىم بولاق سۈپىتىدە تىزىمليدۇ (لايىھە ۋە سىناق نەشرلىرى چىقىرىۋېتىلىدۇ).

## ئىمزا (signing)

قۇرۇش ئىمزاسى ئامباردىكى [`src/android/signing/losfer-debug.keystore`](../src/android/signing/losfer-debug.keystore) غا باغلاندى. بۇ ئاممىۋى debug ئاچقۇچى بولۇپ، دۇكان ئىمزاسى ئەمەس؛ ئۇنى ئامباردا ساقلاشنىڭ مەقسىتى يەرلىك، CI ۋە باشقا تۆھپىكارلارنىڭ ھەر قېتىم **ئوخشاش ئىمزا** چىقىرىشىغا كاپالەتلىك قىلىش، شۇڭا يېڭى APK كونىسىنىڭ ئۈستىگە بىۋاسىتە قاچىلىنىدۇ.

`1.20` ۋە ئۇنىڭدىن بۇرۇنقى نەشرلەر يوقالغان تاسادىپىي ئاچقۇچ بىلەن ئىمزالانغان، شۇڭا `1.22` گە يېڭىلاشتا ئاۋۋال كونا ئەپنى ئۆچۈرۈش كېرەك. `1.22` دىن كېيىن ئىمزا ئۆزگەرمەيدۇ.

## قولدا ئىجرا قىلىش

```sh
python3 scripts/track_upstream.py --check        # ئەسلى ئامبار ھالىتىنى كۆرۈش
python3 scripts/track_upstream.py --write        # ھالەتنى يېزىش
python3 scripts/bump_version.py                  # نەشر نومۇرىنى ئۆستۈرۈش
bash scripts/build_release.sh                    # بارلىق بولاقلارنى قۇرۇش
python3 scripts/make_release_notes.py --version 1.21 --code 43 --out RELEASE_NOTES.md
```

تەپسىلىي قۇرۇش تەلىپى [BUILDING.md](../BUILDING.md) دا. iOS نەشرى Xcode/macOS تەلەپ قىلغانلىقى ئۈچۈن بۇ Linux ئاپتوماتلاشتۇرۇشىغا كىرمەيدۇ؛ Android بولاقلىرى ھەر قېتىم تولۇق قۇرۇلىدۇ.
