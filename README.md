# LOSFER Minis

**ئۈسكۈنىڭىزدە ئىشلەيدىغان شەخسىي AI ۋاكالەتچىسى.**

LOSFER Minis — ئوچۇق كودلۇق [OpenMinis](https://github.com/OpenMinis/OpenMinis) تۈرىنىڭ ئاساسىدا قۇرۇلغان، ئۇيغۇر ئىشلەتكۈچىلىرى ئۈچۈن مەخسۇس تەڭشەلگەن ئەندروىد ئەپى. Claude، GPT، Gemini قاتارلىق داڭلىق مودېللارنى يانفون تەجرىبىسىگە ئېلىپ كىرىدۇ ۋە ئۇلارغا ھەقىقىي كومپيۇتېر بېرىدۇ: ئۈسكۈنىدە ئىشلەيدىغان تولۇق Linux shell، تور كۆرگۈچ ئاۋتوماتلاشتۇرۇش، كېڭەيتىلگەن ماھارەتلەر، ساقلىنىدىغان خاتىرە.

**ئاپتور: Mr-losfer**
**ئامبار: [github.com/Mr-losfer/LOSFER-Minis](https://github.com/Mr-losfer/LOSFER-Minis)**
**LOSFER API ئاچقۇچى ئېلىش: [api.losfer.cn/pc/api-list/keys](https://api.losfer.cn/pc/api-list/keys/)**

| **ھەقىقىي Linux shell** | ئۈسكۈنىدە ئىشلەيدىغان قۇم-ساندۇقلانغان Alpine Linux مۇھىتى — ۋاكالەتچى بوغچا قاچىلاپ، سىكىرىپت ئىجرا قىلالايدۇ. |
| **ئۈسكۈنە بىرىكمىسى** | كالىندار، ئەسكەرتىش، ئالاقىداشلار، كلىپبورد، ئاژۇكلار قاتارلىقلار ۋاكالەتچى قورالى سۈپىتىدە. |
| **تور ئاۋتوماتلاشتۇرۇش** | ۋاكالەتچى سىزنىڭ ئورنىڭىزدا تور بەتلەرنى كۆرىدۇ ۋە مەشغۇلات قىلالايدۇ. |

## قاچىلاش

1. [Releases](https://github.com/Mr-losfer/LOSFER-Minis/releases) بېتىگە كىرىڭ.
2. ئەڭ يېڭى APK نى چۈشۈرۈڭ.
3. تېلېفونىڭىزدا ئېچىپ قاچىلاڭ (نامەلۇم مەنبەلەرگە ئىجازەت زۆرۈر بولۇشى مۇمكىن).
4. ئەپ تۇنجى قېتىم ئېچىلغاندا تىلىڭىزنى تاللاڭ، ئاندىن تەمىنلىگۈچى قوشۇڭ.

### LOSFER ئاچقۇچى ئېلىش

1. [api.losfer.cn/pc/api-list/keys](https://api.losfer.cn/pc/api-list/keys/) بېتىگە كىرىڭ.
2. ھېسابات ئېچىپ ياكى كىرىپ «API ئاچقۇچلىرى» بېتىدىن يېڭى ئاچقۇچ قۇرۇڭ.
3. ئەپنىڭ **تەڭشەكلەر › LOSFER بىر چېكىمدە قۇرۇش** بېتىگە ئاچقۇچنى چاپلاڭ.
4. «تەكشۈرۈش ۋە قوشۇش» نى بېسىڭ — تەييار!

## ئۆزىڭىز قۇرۇش

تەپسىلىي باسقۇچلار [BUILDING.md](BUILDING.md) دا. قىسقىچە:

```sh
git clone --recurse-submodules https://github.com/Mr-losfer/LOSFER-Minis.git
cd LOSFER-Minis
./deps/build_proot.sh && ./scripts/prepare_android_sandbox.sh
cd src/android
./gradlew assembleGithubRelease
```

تەلەپ: Android SDK (API 36)، NDK r28+، CMake 3.22.1، JDK 17+.
