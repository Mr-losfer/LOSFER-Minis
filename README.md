# LOSFER Minis

**ئۈسكۈنىڭىزدە ئىشلەيدىغان شەخسىي AI ۋاكالەتچىسى.**

LOSFER Minis — ئوچۇق كودلۇق [OpenMinis](https://github.com/OpenMinis/OpenMinis) تۈرىنىڭ ئاساسىدا قۇرۇلغان، ئۇيغۇر ئىشلەتكۈچىلىرى ئۈچۈن مەخسۇس تەڭشەلگەن ئەندروىد ئەپى. Claude، GPT، Gemini قاتارلىق داڭلىق مودېللارنى يانفون تەجرىبىسىگە ئېلىپ كىرىدۇ ۋە ئۇلارغا ھەقىقىي كومپيۇتېر بېرىدۇ: ئۈسكۈنىدە ئىشلەيدىغان تولۇق Linux shell، تور كۆرگۈچ ئاۋتوماتلاشتۇرۇش، كېڭەيتىلگەن ماھارەتلەر، ساقلىنىدىغان خاتىرە.

**ئاپتور: Mr-losfer**
**ئامبار: [github.com/Mr-losfer/LOSFER-Minis](https://github.com/Mr-losfer/LOSFER-Minis)**
**LOSFER API ئاچقۇچى ئېلىش: [api.losfer.cn/pc/api-list/keys](https://api.losfer.cn/pc/api-list/keys/)**

## قاچىلاش

1. [Releases](https://github.com/Mr-losfer/LOSFER-Minis/releases) بېتىگە كىرىڭ.
2. ئەڭ يېڭى APK نى چۈشۈرۈڭ.
3. تېلېفونىڭىزدا ئېچىپ قاچىلاڭ (نامەلۇم مەنبەلەرگە ئىجازەت زۆرۈر بولۇشى مۇمكىن).
4. ئەپ تۇنجى قېتىم ئېچىلغاندا تىلىڭىزنى تاللاڭ، ئاندىن تەمىنلىگۈچى قوشۇڭ.

### LOSFER ئاچقۇچى ئېلىش

1. [api.losfer.cn/pc/api-list/keys](https://api.losfer.cn/pc/api-list/keys/) بېتىگە كىرىڭ.
2. ھېسابات ئېچىپ ياكى كىرىپ «API ئاچقۇچلىرى» بېتىدىن يېڭى ئاچقۇچ قۇرۇڭ.
3. ئەپنىڭ **تەڭشەكلەر › LOSFER بىر چېكىمدە قۇرۇش** بېتىگە ئاچقۇچنى چاپلاڭ.
4. «تەكشۈرۈش ۋە قوشۇش» نى بېسىڭ — تەييار!

## يېڭىلىنىش

ئەپ ئۆزلۈكىدىن مۇشۇ ئامبارنىڭ Releases بېتىنى تەكشۈرىدۇ: يېڭى نەشرى چىققاندا ئۇقتۇرۇش كۆرۈنىدۇ ۋە ئەپ ئىچىدىلا APK نى چۈشۈرۈپ قاچىلىيالايسىز. ھەر قېتىملىق كود يېڭىلاش ۋە ئورۇنلاشتۇرما ھۆججەتلىرى مۇشۇ ئامبارغا يوللىنىدۇ.

### ئەسلى ئامبارنى ئاپتوماتىك ئىز قوغلاش

[OpenMinis/OpenMinis](https://github.com/OpenMinis/OpenMinis) ئەسلى ئامبىرى ھەر كۈنى ئاپتوماتىك تەكشۈرۈلىدۇ. يېڭى نەشر، خەتكۈچ ياكى كود يوللاش بايقالسا تۆۋەندىكى زەنجىر ئۆزلۈكىدىن ئىجرا بولىدۇ:

1. نەشر نومۇرى (`versionName`) ۋە قۇرۇش نومۇرى (`versionCode`) بىرگە ئاشۇرۇلىدۇ؛
2. **ھەر بىر** ئورۇنلاشتۇرما بولاق (`arm64-v8a` APK ۋە AAB) قايتا قۇرۇلىدۇ؛
3. ئۆزگىرىشلەر `git` غا يوللىنىدۇ؛
4. ئۇيغۇرچە نەشر خاتىرىسى بىلەن **رەسمىي** (`draft` ئەمەس، `prerelease` ئەمەس) Releases تىزىملىكىگە يوللىنىدۇ.

تەپسىلىي ھالەت ۋە ئەسلى ئامبارنىڭ 1.16 سىناق نەشرلىرىدىكى يېڭى ئىقتىدارلار جەدۋىلى [docs/UPSTREAM_TRACKING.md](docs/UPSTREAM_TRACKING.md) دا. قولدا قوزغىتىش ئۈچۈن GitHub دىكى «ئەسلى ئامبارنى ئىز قوغلاش ۋە رەسمىي نەشر» workflow نى ئىجرا قىلىڭ.

> ئەسلى ئامبار `1.16-beta.1…1.16-beta.5` نەشرلىرىنى پەقەت APK شەكلىدە ئېلان قىلدى، ماس كود يوللانمىدى (خەتكۈچلەرنىڭ ھەممىسى `1a71df0` غا ئىشارە قىلىدۇ). شۇڭا ئۇلارنىڭ يېڭى ئىقتىدارلىرى بىۋاسىتە بىرلەشتۈرۈلمەي، ئىز قوغلاش جەدۋىلىگە كىرگۈزۈلدى؛ كود ئېلان قىلىنغان ھامان ئاپتوماتىك يېڭى نەشر چىقىرىلىدۇ.

### 1.21-نەشرىدىكى يېڭىلىقلار

- ئەسلى ئامبارنى ئىز قوغلاش ئاپتوماتلاشتۇرۇلدى: كۈندىلىك [`upstream-follow.yml`](.github/workflows/upstream-follow.yml) ۋە [`scripts/track_upstream.py`](scripts/track_upstream.py) ئەسلى ئامبارنىڭ Release، خەتكۈچ ۋە كود يوللاشلىرىنى `gh-proxy.com` ئەينىكى ئارقىلىق تەكشۈرۈپ، ئۇيغۇرچە ھالەت ھۆججىتىنى يېڭىلايدۇ.
- ھەر قېتىملىق يېڭىلاشتا `git` يوللاش، نەشر نومۇرىنى ئۆستۈرۈش، **ھەر بىر** بولاقنى قايتا قۇرۇش ۋە رەسمىي Releases تىزىملىكىگە يوللاش بىر زەنجىرگە باغلاندى ([`scripts/build_release.sh`](scripts/build_release.sh)).
- بولاق نامى `LOSFER-Minis-<نەشر>-build<نومۇر>-<ABI>.apk` قائىدىسىگە ئۆزگەرتىلدى؛ ئەپ ئىچىدىكى يېڭىلاش تەكشۈرۈشى ئەمدى قۇرۇش نومۇرى ۋە ABI نى توغرا ئوقۇيدۇ، سىناق يولىمۇ نومۇر بويىچە سېلىشتۇرالايدۇ. ئەسلى ئامبارنىڭ `MinisApp-...` فورماتىمۇ داۋاملىق تونۇلىدۇ.
- رەسمىي بولاقلار تىزىملىكىدىن لايىھە ۋە سىناق نەشرلىرى چىقىرىۋېتىلىدۇ؛ بىر نەشردىكى ھەر بىر APK/AAB ئايرىم بولاق سۈپىتىدە تىزىملىنىدۇ.
- قۇرۇش ئىمزاسى ئامباردىكى تۇراقلىق debug ئاچقۇچىغا باغلاندى، شۇڭا يەرلىك ۋە CI دا قۇرۇلغان بولاقلارنىڭ ئىمزاسى ئوخشاش چىقىدۇ. **دىققەت:** `1.20` ۋە ئۇنىڭدىن بۇرۇنقى نەشرلەردىن `1.21` گە يېڭىلاشتا ئاۋۋال كونا ئەپنى ئۆچۈرۈش كېرەك؛ كېيىنكى نەشرلەردە ئۇنداق ئەمەس.

### 1.20-نەشرىدىكى يېڭىلىقلار

- ماھارەتلەر بېتىنىڭ ئەڭ ئۈستىگە «LOSFER ماھارەت ئامبىرىنى چۈشۈرۈش» قوشۇلدى: بىر چېكىمدە تەڭشەلگەن GitHub ئامبىرىدىكى بارلىق ماھارەت بوغچىلىرى (`SKILL.md`، `scripts`، `references` قاتارلىق قوشۇمچە ھۆججەتلەر بىلەن) چۈشۈرۈلۈپ قاچىلىنىدۇ.
- ئامبار ئادرېسى [losfer-skills.json](losfer-skills.json) ھۆججىتىدە ساقلىنىدۇ؛ سۈكۈمىتى `https://github.com/NoraStory/reverse-SKILL` (50 گە يېقىن ماھارەت بوغچىسى). يېڭى ئامبار قوشۇش ئۈچۈن پەقەت بۇ ھۆججەتنى تەھرىرلەش كېرەك، ئەپنى قايتا قۇرۇشنىڭ ھاجىتى يوق.
- تىزىملىك ۋە ئامبار ZIP ھۆججىتى ئاۋۋال `https://gh-proxy.com/` ئەينىكى ئارقىلىق چۈشۈرۈلىدۇ؛ تۇتاشمىسا بىۋاسىتە GitHub غا قايتىدۇ.
- لاتىنچە بولمىغان ماھارەت ناملىرى ئۈچۈن تۇراقلىق خەش (hash) ئاساسىدا كىملىك ھاسىل قىلىنىدۇ، شۇڭا ئوخشاش ياكى پۈتۈنلەي خەنزۇچە ناملىق ماھارەتلەر بىر-بىرىنى يېپىپ قالمايدۇ؛ قايتا چۈشۈرۈش يېڭىلاش ھېسابلىنىدۇ.
- ماھارەتلەر بېتىگە «ھەممىسىنى ئېچىش / ھەممىسىنى تاقاش» كۇنۇپكىلىرى ۋە ئېچىلغان ماھارەت سانى قوشۇلدى.

### 1.19-نەشرىدىكى يېڭىلىقلار

- ئۇيغۇرچە تاللانغاندا پۈتۈن ئەپ ئوڭدىن سولغا (RTL) ئەينەكلىنىدۇ، ئەمما **سۆھبەت بېتى ئەينەكلەنمەيدۇ**: ئۇچۇر كۆپۈكچىلىرى، يېزىش رامكىسى، قورال بالداق، دومىلاش بالدىقى ۋە سۆھبەتتىن ئېچىلىدىغان بارلىق كۆزنەكلەر ئەسلىدىكى سولدىن ئوڭغا (LTR) ئورنىدا تۇرىدۇ. ئۇيغۇرچە تېكىست ئۆز پارچىسى ئىچىدە يەنىلا ئوڭدىن سولغا ئوقۇلىدۇ؛ پەقەت رامكا مۇقىملاشتۇرۇلىدۇ.
- سۆھبەتنى PNG/PDF قىلىپ چىقىرىش ۋە ۋاكالەتچى سۆھبەت خاتىرىسى بېتىمۇ ئوخشاش LTR كۆرۈنۈشنى ئىشلىتىدۇ، شۇڭا چىقىرىلغان ھۆججەت ئېكراندىكى بىلەن بىر خىل كۆرۈنىدۇ.
- تىل تەڭشىكىدىكى سۈكۈمىتى خەت نۇسخىسى ئىزاھاتى UKIJ Tuz غا تۈزىتىلدى.

### 1.18-نەشرىدىكى يېڭىلىقلار

- يېڭىلاشنى تەكشۈرۈش ۋە APK چۈشۈرۈش `gh-proxy.com` ئەينىكىنى ئالدىن ئىشلىتىدۇ؛ مەغلۇپ بولسا ئۆزلۈكىدىن بىۋاسىتە GitHub غا قايتىدۇ.
- LOSFER بىر چېكىمدە قۇرۇش قاتارلىق 22 يېڭى تىللىق بايلىق 22 خىل تىلغا تەرجىمە قىلىندى — ئەمدى قايسى تىلنى تاللىسىڭىزمۇ ئىنگلىزچىغا قايتمايدۇ.
- خەت نۇسخىسى چۈشەندۈرۈشىدىكى كونا ALKATIP Asliya ئۇچۇرى UKIJ Tuz غا تۈزىتىلدى.

### 1.17-نەشرىدىكى يېڭىلىقلار

- ئەپتىكى 2493 تىللىق بايلىقنىڭ ھەممىسى ئۇيغۇرچىغا تەرجىمە قىلىندى (ئىلگىرى پەقەت 566 سى بار ئىدى).
- سۈكۈمىتى كۆرۈنۈش تىلى ئۇيغۇرچە قىلىندى؛ شۇڭا ئەپ تۇنجى ئېچىلغاندا LOSFER بىر چېكىمدە قۇرۇشنى ئۆز ئىچىگە ئالغان بارلىق ئېكرانلار ئۇيغۇرچە كۆرۈنىدۇ.
- باش بەتتىكى قارشى ئېلىش تېمىسى «LOSFER Minis» غا ئۆزگەرتىلدى، ئۈچ قەدەملىك تەڭشەش كارتىلىرىنىڭ ئۈستىگە LOSFER بىر چېكىمدە قۇرۇش كارتىسى قوشۇلدى.
- سۈكۈمىتى ئۇيغۇرچە خەت نۇسخىسى UKIJ Tuz قىلىندى.

### 1.16-نەشرىگە يېڭىلاشتا دىققەت

1.16-نەشرىدىن باشلاپ ئەپنىڭ بولاق نامى `cn.losfer.minis` غا ئۆزگەرتىلدى (ئىلگىرى `com.openminis.app` ئىدى). ئەندروىد بۇ ئىككىسىنى ئايرىم ئەپ دەپ ھېسابلايدۇ، شۇڭا:

- كونا نەشرنىڭ ئۈستىگە بىۋاسىتە قاچىلىغىلى بولمايدۇ؛ ئاۋۋال كونا ئەپنى ئۆچۈرۈپ، ئاندىن يېڭى APK نى قاچىلاڭ.
- كونا ئەپنىڭ سۆھبەت خاتىرىسى، تەڭشەكلىرى ۋە API ئاچقۇچلىرى يېڭى ئەپكە ئۆزلۈكىدىن كۆچۈرۈلمەيدۇ، قايتىدىن كىرگۈزۈشكە توغرا كېلىدۇ.
- ئەپ ئىچىدىكى يېڭىلىنىش تەكشۈرۈشى 1.16 دىن كېيىنكى نەشرلەردە نورمال ئىشلەيدۇ.

## ئۆزىڭىز قۇرۇش

تەپسىلىي باسقۇچلار [BUILDING.md](BUILDING.md) دا. قىسقىچە:

```sh
git clone --recurse-submodules https://github.com/Mr-losfer/LOSFER-Minis.git
cd LOSFER-Minis
./deps/build_proot.sh && ./scripts/prepare_android_sandbox.sh
cd src/android
./gradlew assembleGithubRelease
```

تەلەپ: Android SDK (API 36)، NDK r28+، CMake 3.22.1، JDK 17+.
